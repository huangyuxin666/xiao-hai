## 数据库实体表

### 1. 用户表 user

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | bigint | PK, AUTO_INCREMENT | 主键 |
| student_id | varchar(20) | NOT NULL, UNIQUE | 学号 |
| name | varchar(50) | NOT NULL | 姓名 |
| password | varchar(255) | NOT NULL | 密码（加密存储） |
| college | varchar(100) | NOT NULL | 学院 |
| phone | varchar(20) | | 电话 |
| role | varchar(20) | DEFAULT 'STUDENT' | 角色：STUDENT / ADMIN |
| status | int | DEFAULT 0 | 0-正常, 1-禁用 |
| avatar | varchar(500) | | 头像URL |
| reputation_score | decimal(3,2) | DEFAULT 5.00 | 信誉积分 |
| create_time | datetime | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | datetime | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

### 2. 商品表 product

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | bigint | PK, AUTO_INCREMENT | 主键 |
| user_id | bigint | FK→user, NOT NULL | 卖家ID |
| title | varchar(100) | NOT NULL | 商品标题 |
| description | text | | 商品描述 |
| price | decimal(10,2) | NOT NULL | 价格 |
| category | varchar(50) | NOT NULL | 分类 |
| images | text | | 图片URL，逗号分隔 |
| status | varchar(20) | DEFAULT 'ACTIVE' | ACTIVE / SOLD / OFFLINE |
| view_count | int | DEFAULT 0 | 浏览次数 |
| create_time | datetime | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | datetime | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

### 3. 订单表 orders

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | bigint | PK, AUTO_INCREMENT | 主键 |
| order_no | varchar(50) | NOT NULL, UNIQUE | 订单号 |
| buyer_id | bigint | FK→user, NOT NULL | 买家ID |
| seller_id | bigint | FK→user, NOT NULL | 卖家ID |
| product_id | bigint | FK→product, NOT NULL | 商品ID |
| product_name | varchar(100) | NOT NULL | 商品名称（冗余） |
| product_image | varchar(500) | | 商品图片 |
| price | decimal(10,2) | NOT NULL | 成交价格 |
| pickup_point_id | bigint | | 取货点ID |
| pickup_code | varchar(10) | | 取货码 |
| status | varchar(20) | NOT NULL | PENDING/CONFIRMED/SHIPPED/COMPLETED/CANCELLED |
| cancel_reason | varchar(500) | | 取消原因 |
| create_time | datetime | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | datetime | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |
| finish_time | datetime | | 完成时间 |

### 4. 购物车表 cart

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | bigint | PK, AUTO_INCREMENT | 主键 |
| user_id | bigint | FK→user, NOT NULL | 用户ID |
| product_id | bigint | FK→product, NOT NULL | 商品ID |
| quantity | int | DEFAULT 1 | 数量 |
| create_time | datetime | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | datetime | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

### 5. 收藏表 favorite

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | bigint | PK, AUTO_INCREMENT | 主键 |
| user_id | bigint | FK→user, NOT NULL | 用户ID |
| product_id | bigint | FK→product, NOT NULL | 商品ID |
| create_time | datetime | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 6. 消息表 message

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | bigint | PK, AUTO_INCREMENT | 主键 |
| sender_id | bigint | FK→user, NOT NULL | 发送者ID |
| receiver_id | bigint | FK→user, NOT NULL | 接收者ID |
| product_id | bigint | | 关联商品ID |
| order_id | bigint | ON DELETE SET NULL | 关联订单ID |
| content | varchar(1000) | NOT NULL | 消息内容 |
| is_read | tinyint(1) | DEFAULT 0 | 是否已读 |
| create_time | datetime | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 7. 评价表 review

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | bigint | PK, AUTO_INCREMENT | 主键 |
| order_id | bigint | FK→orders, UNIQUE, NOT NULL | 订单ID（一单一评） |
| reviewer_id | bigint | FK→user, NOT NULL | 评价人ID |
| reviewee_id | bigint | FK→user, NOT NULL | 被评价人ID |
| rating | int | NOT NULL | 评分 1-5 |
| content | varchar(500) | | 评价内容 |
| create_time | datetime | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

### 8. 担保流水表 escrow_record

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | bigint | PK, AUTO_INCREMENT | 主键 |
| order_id | bigint | NOT NULL | 订单ID |
| order_no | varchar(50) | NOT NULL | 订单号 |
| user_id | bigint | NOT NULL | 用户ID |
| user_type | varchar(20) | NOT NULL | BUYER / SELLER |
| type | varchar(30) | NOT NULL | FREEZE / RELEASE / REFUND |
| amount | decimal(10,2) | NOT NULL | 金额 |
| status | varchar(20) | NOT NULL | PENDING / COMPLETED / CANCELLED |
| related_id | bigint | | 关联ID（如退款申请） |
| remark | text | | 备注 |
| create_time | datetime | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| update_time | datetime | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |
